# Showcase Scope

This repository is designed for public portfolio review. It focuses on product clarity, marketplace outcomes, and a simplified technical overview of Taskquatch.

## Public Content

- Product positioning
- Marketplace metrics
- Representative product surfaces using approved placeholders or sanitized simulator captures
- High-level architecture
- Trust and safety workflow summaries
- Marketplace operations summaries
- Reliability and automation capability summaries
- Growth, payments, realtime, and admin tooling summaries
- Technical stack highlights
- Builder attribution

## Intentionally Omitted

- Production source code
- Backend implementation details
- Secrets and credentials
- Private infrastructure state
- Customer, vendor, payment, or operational records
- Provider payloads, webhook details, storage paths, logs, or identifiers
- Private admin screenshots or internal dashboard data
- Proprietary business logic

## Maintenance Notes

When adding screenshots or copy updates, keep the repository public-safe. Use approved marketing assets or sanitized simulator captures only, and avoid exposing internal dashboards, API payloads, logs, identifiers, real customer/vendor data, or operational details that are not intended for public distribution.
